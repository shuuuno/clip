# Clip 0.6.0

Windows용 개인 캡처·녹화 도구입니다. 이미지를 편집하고, 화면을 MP4로 녹화하거나 녹화 구간을 GIF로 내보냅니다.

## 실행

`artifacts/Clip-win-x64.zip`을 폴더에 풀고 **Clip.exe**를 실행하세요. 폴더의 파일을 함께 유지해야 하며 .NET 별도 설치는 필요하지 않습니다.

직원에게 공유할 때는 버전이 붙은 `Clip-0.6.0-win-x64.zip`을 전달하세요. [공유·처음 실행 안내](docs/sharing.md)에 실행, 데이터 보관, 새 버전 교체 방법을 정리했습니다.

1. **새 캡처** 또는 기본 **Ctrl+Shift+2**로 시작합니다.
2. 영역을 드래그한 뒤 **마우스를 놓으면 캡처가 완료되고 즉시 클립보드에 복사**됩니다. Enter는 필요 없습니다. 드래그 중 **Esc / 우클릭**으로 취소할 수 있습니다. 움직이지 않은 단순 클릭은 캡처하지 않습니다.
3. 번호·박스·텍스트·모자이크를 추가하거나 크롭합니다.
4. **Ctrl+C**로 편집 이미지를 복사하거나 **Ctrl+S**로 PNG를 저장합니다.

창을 닫으면 트레이에 남습니다. 완전히 종료하려면 트레이 아이콘 우클릭 → **Clip 종료**를 선택하세요. 다른 앱이 단축키를 사용 중이면 새 캡처 버튼을 이용하고 설정에서 조합을 바꿀 수 있습니다.

제목 표시줄은 앱 상단과 통합되어 있습니다. 상단 빈 영역을 드래그하면 창이 이동하고 두 번 클릭하면 최대화·복원됩니다. 오른쪽의 최소화·최대화·닫기와 창 가장자리 크기 조절을 사용할 수 있습니다.

## 로그인 시 자동 실행

**설정 → Windows 로그인 시 시작 → 저장**으로 켜고 끕니다. 기본은 미등록이며, 앱을 열기만 해서는 등록하지 않습니다. 자동 실행으로 시작하면 편집 창 없이 트레이에서 대기합니다. Clip을 다시 실행하거나 트레이를 더블클릭하면 기존 창을 엽니다.

현재 사용자에게만 실행 파일과 데이터 폴더의 경로를 등록합니다. Clip 폴더를 이동하거나 새 버전 폴더로 바꾸면 새 위치에서 이 옵션을 다시 켜고 저장하세요. 삭제 전에는 등록한 앱에서 옵션을 끄세요. 다른 위치의 Clip이 등록된 경우 현재 복사본에서 끄는 것만으로 그 항목을 지우지 않습니다. Windows의 시작 앱 설정이나 회사 정책이 실행을 막으면 그 상태를 강제로 변경하지 않습니다. 실제 재부팅·로그인 주기는 아직 검증하지 않았습니다.

## 편집

| 작업 | 조작 |
|---|---|
| 선택·이동 | V, 주석 클릭 후 드래그. 방향키 1px / Shift+방향키 10px |
| 번호 | N, 클릭할 때마다 번호 증가 |
| 사각형 | R, 드래그 |
| 텍스트 | T, 위치 클릭 → 입력 → Ctrl+Enter 또는 추가 |
| 모자이크 | M, 가릴 영역 드래그. 굵기가 클수록 블록이 커짐 |
| 크롭 | C, 남길 영역 드래그 → Enter / 크롭 적용. Esc 취소 |
| 가로 띠 제거 | H, 위아래로 제거할 구간 드래그 → Enter / 띠 제거 적용 |
| 세로 띠 제거 | J, 좌우로 제거할 구간 드래그 → Enter / 띠 제거 적용 |
| 삭제 | V로 주석 선택 후 Delete |
| 되돌리기 / 다시 실행 | Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y |
| 녹화 영역 선택 후 미세 조정 | 방향키로 영역 이동, Shift+방향키로 너비·높이 1px 변경 |

색·굵기·글자 크기는 **새로 그리는 주석**에 적용됩니다. 저장하지 않은 편집을 닫거나 교체할 때 저장 여부를 묻습니다.

도구 오른쪽에서 단축키를 확인할 수 있습니다. 현재 도구에 적용되는 속성만 활성화하며, 선택한 도구는 배경과 테두리로 표시합니다. 하단 왼쪽에서 크롭·띠 제거를 적용하고 오른쪽에서 PNG 저장·복사를 실행합니다.

띠 제거는 이미지 전체 폭의 행 또는 전체 높이의 열을 삭제하고 **빈틈 없이 바로 붙입니다**. 빨간 선택 영역과 적용 후 크기를 확인한 뒤 Enter로 적용하세요. Esc 또는 다른 도구 선택은 적용 전 선택을 취소합니다. 가장자리·1픽셀 띠도 제거할 수 있으며 이미지 전체를 없애는 선택은 차단합니다.

띠 제거 시 기존 주석·모자이크를 이미지에 합성해 함께 자릅니다. 합성된 주석은 개별 이동할 수 없으며, **Ctrl+Z로 원래 이미지와 주석을 함께 복원**할 수 있습니다. Ctrl+Shift+Z는 다시 실행입니다. 저장·클립보드에는 같은 최종 이미지가 들어가고 원본 파일은 덮어쓰지 않습니다. 투명 간격은 추가하지 않습니다.

## 영역 녹화

1. **영역 녹화** 또는 **Ctrl+Shift+9**를 누릅니다.
2. 한 모니터 안에서 녹화할 영역을 드래그하고 **Enter**로 확정합니다. Esc는 취소입니다.
3. 준비창에서 **녹화 시작** 또는 **Ctrl+Shift+9**를 누릅니다.
4. **정지·저장** 또는 **Ctrl+Shift+9**로 마칩니다. 녹화창을 닫아도 정지 후 저장합니다.
5. 라이브러리의 **MP4 항목**을 클릭하면 Clip 안에서 재생·일시 정지·처음부터 재생할 수 있습니다.

- **소리와 마우스 포인터는 녹화하지 않습니다.** 현재 구현은 화면 영상 전용입니다.
- H.264 MP4, 목표 30fps입니다. 처리량이 부족하면 동일 프레임을 반복하며 실제 경과 시간을 유지합니다.
- 선택 크기가 홀수이면 오른쪽·아래에 최대 1px 검정 여백을 넣어 짝수 크기로 저장합니다. 원래 영역을 잘라내거나 확대하지 않습니다.
- 최소 2×2px, 각 변 최대 3840px, 전체 면적은 3840×2160px 이하입니다. 매우 작은 영역이나 큰 영역의 인코딩은 Windows 코덱에 따라 실패할 수 있습니다.
- 녹화 제어창을 캡처에서 제외합니다. Windows 10 2004 이전 또는 제외 기능 실패 시 녹화 중 제어창을 숨깁니다. 이때 단축키나 **트레이 → 영역 녹화 / 정지·저장**으로 정지하세요.
- Ctrl+Shift+9가 다른 앱과 충돌하면 준비창에 안내합니다. 버튼과 트레이 메뉴로 사용할 수 있습니다. 녹화 단축키는 현재 고정입니다.
- 모니터 구성 변경 시 녹화를 정지하고 저장하도록 처리합니다. 실제 모니터 연결 변경 시험은 아직 하지 않았습니다.
- 인코딩 완료 후에만 최종 MP4를 라이브러리에 표시합니다. 완료 파일의 최종 이동에 실패하면 오류에 표시된 `.clip-recording-*.partial.mp4`를 복구용으로 보존합니다. 강제 종료·전원 차단 중 녹화의 복구는 보장하지 않습니다.
- Windows 내장 Media Foundation을 사용합니다. 별도 FFmpeg 설치는 필요 없습니다. 미디어 기능이 빠진 Windows N 등에서는 녹화가 실패할 수 있습니다.

## GIF 내보내기

1. 라이브러리에서 **MP4**를 엽니다.
2. 재생창의 **GIF 내보내기**를 누릅니다.
3. 시작·끝 시간을 초 단위로 입력하고 가로 크기와 초당 프레임 수를 고릅니다.
4. **GIF 저장**을 누르면 현재 저장 폴더에 새 파일을 만듭니다. 원본 MP4는 유지됩니다.
5. **GIF 보기** 또는 라이브러리의 GIF 항목에서 반복 재생합니다.

- 구간은 **0.1~30초**, 가로·세로 각각 **1280px 이내**, **5~30fps**를 지원합니다. 비율을 유지하고 원본보다 확대하지 않습니다.
- 기본값은 처음 최대 10초, 가로 최대 640px, 15fps입니다. GIF는 256색 팔레트를 사용하므로 사진·그라데이션의 색이 달라질 수 있습니다.
- 항상 무한 반복 GIF로 저장합니다. GIF의 10ms 시간 단위에 맞춰 프레임 지연을 분배하며 전체 길이 오차는 최대 약 5ms입니다.
- **변환 취소**는 임시 결과를 정리하고 옵션 창을 유지합니다. 변환 중 창을 닫거나 트레이에서 앱을 종료하면 취소·정리가 끝난 뒤 닫힙니다.
- 길이·크기·fps가 크면 파일도 커집니다. 예를 들어 합성 영상 30초·1280×720·30fps 시험 결과는 약 124MiB였습니다. 짧은 구간과 작은 크기로 먼저 저장해 보세요.
- 미리보기는 Clip에서 만든 전체 프레임 GIF를 기준으로 합니다. 외부 GIF의 부분 프레임·투명도·프레임 복원 방식은 지원하지 않을 수 있습니다.
- 별도 FFmpeg 설치가 필요 없습니다. Windows 미디어 기능으로 MP4를 읽고 Windows 이미지 인코더로 GIF를 만듭니다.

## 저장 정책

- 캡처 확정 시 클립보드에 자동 복사하고 편집기로 엽니다. 주석을 추가한 뒤에는 Ctrl+C로 편집 결과를 다시 복사하세요. PNG 저장은 Ctrl+S로 별도 수행합니다.
- 클립보드가 사용 중이면 재시도하고, 계속 실패해도 캡처는 편집기에 남깁니다. 실패 안내 후 복사 버튼을 다시 누를 수 있습니다.
- PNG에는 모든 주석과 모자이크가 최종 픽셀로 합성됩니다. 원본·주석 JSON을 옆에 따로 남기지 않습니다.
- 다시 열면 주석도 이미지의 일부입니다. 개별 객체 재편집은 현재 편집 세션에서만 가능합니다.
- 크롭은 현재 편집 결과를 합성해서 자릅니다. 같은 세션의 Ctrl+Z로 원본과 주석을 복원할 수 있습니다.
- 저장할 때마다 새 파일을 만듭니다. 열었던 원본이나 기존 파일을 덮어쓰지 않습니다.
- 라이브러리는 설정된 폴더의 최근 PNG·MP4·GIF 합계 최대 500개를 표시합니다. 저장 폴더를 바꿔도 기존 파일은 이동하지 않습니다.
- 이 작업 폴더에서 실행하면 기본 데이터는 `data/`, 복사한 포터블 폴더에서 실행하면 `Clip.exe` 옆 `data/`에 있습니다. `--data-dir <폴더>`로 분리 실행할 수 있습니다.

## 현재 범위

이미지 캡처·즉시 복사·주석·크롭·가로/세로 띠 제거·모자이크·PNG·클립보드·영역 MP4 녹화·GIF 구간 내보내기·영상/GIF 재생·라이브러리·설정·트레이·로그인 자동 실행 옵션을 포함합니다. 소리·포인터 녹화, MP4 편집, 창 자동 감지, 스크롤 캡처, OCR, 업데이트 설치는 포함하지 않습니다.

Windows x64용입니다. 실제 검증한 OS·배율 및 남은 환경은 [검증 기록](docs/acceptance.md)을 확인하세요. 혼합 DPI·HDR·다른 Windows 버전의 검증을 현재 PC의 결과로 대신하지 않습니다.

## 개발

프로젝트 로컬 .NET SDK 10.0.403을 사용합니다. 새 체크아웃은 [Microsoft 공식 설치 스크립트](https://learn.microsoft.com/dotnet/core/tools/dotnet-install-script)로 `.tools/dotnet`에 SDK를 설치하세요. SDK·패키지·CLI·임시 경로는 `scripts/env.ps1`에서 프로젝트 안으로 지정합니다.

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
.\scripts\publish.ps1
```

검증은 STA 환경의 독립 실행형 C# 테스트 프로그램입니다. 픽셀·파일·설정·실제 단축키 충돌을 검사하며 실패 시 종료 코드 1을 반환합니다. 외부 테스트 패키지 없이 실행합니다.

`src/Clip`만 제품 코드입니다. `_reference`의 참고 앱·역컴파일·자산·분석 도구는 제품 빌드와 배포에 포함하지 않습니다. Clip 코드는 관찰한 기능을 바탕으로 새로 작성했습니다.
