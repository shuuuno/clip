# Clip 0.5 — 공유·처음 실행 안내

Clip은 Windows x64용 포터블 캡처 앱입니다. 현재 버전은 이미지 캡처·주석·모자이크·크롭·띠 제거, 무음 MP4 녹화, GIF 내보내기를 지원합니다. 별도 .NET 설치는 필요하지 않습니다. 실제 검증 환경은 Windows 11이며 Windows 10 실기 검증은 아직 하지 않았습니다.

## 처음 실행

1. 전달받은 `Clip-0.5.0-win-x64.zip`을 각자 PC의 쓰기 가능한 개인 폴더에 **모두 풀어** 주세요. 예: 문서 아래 `Clip` 폴더.
2. 압축을 푼 폴더의 `Clip.exe`를 실행하세요. EXE만 따로 옮기면 안 됩니다.
3. **설정**에서 캡처 저장 위치를 확인하세요. 로그인 시 트레이에서 시작하려면 **Windows 로그인 시 시작**을 켜고 저장하세요. 기본으로 켜지지는 않습니다.

ZIP 안에서 바로 실행하거나 공용 폴더의 같은 실행본·데이터를 여러 사람이 함께 쓰지 마세요. 회사 PC에서 실행이 차단되면 담당자에게 확인하고 회사 보안 설정을 임의로 바꾸지 마세요.

## 자주 쓰는 조작

| 작업 | 방법 |
|---|---|
| 캡처·즉시 복사 | Ctrl+Shift+2 → 드래그 → Enter → 원하는 곳에 붙여넣기 |
| 복사 / PNG 저장 | Ctrl+C / Ctrl+S |
| 주석 | 번호 N, 박스 R, 텍스트 T, 모자이크 M |
| 크롭 | C → 남길 영역 드래그 → Enter |
| 띠 제거 | 가로 H / 세로 J → 제거할 구간 드래그 → Enter |
| 취소 / 되돌리기 | Esc / Ctrl+Z |
| 영역 녹화 | Ctrl+Shift+9 → 영역 선택·Enter → 녹화 시작 → 같은 단축키로 정지 |
| GIF | 라이브러리 MP4 열기 → GIF 내보내기 |
| 완전히 종료 | 트레이 Clip 아이콘 우클릭 → Clip 종료 |

창의 X는 트레이로 숨깁니다. 단축키가 다른 앱과 겹치면 앱의 버튼을 사용하세요. 캡처 단축키는 설정에서 바꿀 수 있습니다. 녹화는 현재 소리·마우스 포인터를 포함하지 않습니다. GIF는 최대 30초, 각 변 1280px입니다.

## 데이터와 새 버전

공유 ZIP을 다른 PC에 풀면 기본 설정·캡처는 `Clip.exe` 옆 `data` 폴더에 저장됩니다. 설정에서 바꾼 캡처 폴더는 별도로 유지됩니다. 개발 프로젝트 안에서 실행한 경우에는 프로젝트 루트의 `data`를 사용합니다.

새 버전으로 바꿀 때는 먼저 트레이에서 Clip을 종료하고 `data`와 별도 캡처 폴더를 백업하세요. 새 ZIP은 새 폴더에 풉니다. 라이브러리를 이어 쓰려면 새 앱의 설정에서 기존 캡처 폴더를 지정하세요. 단축키는 필요하면 다시 설정합니다. 자동 실행을 사용했다면 새 앱에서 옵션을 다시 켜고 저장해 새 위치를 등록하세요. 앱을 완전히 없앨 때는 등록한 앱에서 자동 실행 옵션부터 끄세요. 기존 파일을 확인한 뒤에 이전 앱 폴더를 정리하세요. 폴더를 삭제하면 그 안의 `data`도 함께 없어지므로 주의하세요.

직원에게는 제공된 배포 ZIP을 공유하세요. 본인이 사용하던 폴더를 다시 압축하면 개인 설정과 캡처가 함께 들어갈 수 있습니다. 소스, 참고 앱 분석 자료, 테스트 결과는 공유 ZIP에 포함하지 않습니다.

## 문제가 생기면

버전(0.5.0), Windows 버전, 모니터 수·배율, 누른 버튼과 발생 순서를 알려 주세요. 가능하면 업무 정보가 없는 합성 화면으로 재현해 주세요. 다중 모니터·혼합 배율·장시간 녹화는 추가 실사용 확인이 필요합니다.
